# Adurite Digital Store

This is a complete digital products e-commerce store built with HTML, CSS, and JavaScript.

## Features
- Dark theme design with modern aesthetics
- Fully responsive design for all devices
- Multi-page website (Home, About, Products, Contact, Cart)
- Product listings with filtering
- Shopping cart functionality
- Contact form
- Mobile-friendly navigation

## Pages Included
- Home Page
- About Page
- Products Page
- Contact Page
- Shopping Cart Page

## Design Highlights
- Dark theme with gradient accents
- Modern card-based design
- Smooth animations and transitions
- Mobile-first responsive layout
- Professional typography

## Getting Started
1. Clone the repository
2. Open index.html in your browser
3. For live deployment, push to GitHub Pages

## Folder Structure
- `index.html` - Home page
- `about.html` - About page
- `products.html` - Products page
- `contact.html` - Contact page
- `cart.html` - Shopping cart page
- `styles/style.css` - All CSS styling
- `scripts/main.js` - JavaScript functionality
- `assets/images/` - Image assets
